## Overview

This project demonstrates a small, reproducible R workflow for exploring a **synthetic customer-order dataset**. The analysis imports order records, validates the input fields, calculates descriptive summaries, compares revenue by region and product category, and creates a revenue-by-region chart.

## Dataset

The dataset contains 20 fictional orders and the following variables:

| Variable | Type | Description |
|---|---|---|
| `order_id` | Character | Synthetic order identifier |
| `order_date` | Date | Fictional transaction date |
| `region` | Character | Canadian sales region |
| `category` | Character | Product category |
| `units` | Integer | Number of units ordered |
| `unit_price` | Numeric | Price per unit in Canadian dollars |

No real customer names, contact details, or personal information are included.

## Usage

Run the analysis from the repository root:

```r
source("scripts/customer_orders_analysis.R")
```

The script will:

1. read `data/synthetic_customer_orders.csv`;
2. verify that required columns and valid values are present;
3. calculate revenue for each order;
4. print overall and grouped summaries;
5. save summary tables in `outputs/`; and
6. save `outputs/revenue_by_region.png`.

To review the documentation, open `customer_orders_documentation.Rmd` and select **Knit** or **Preview** in RStudio/Posit Cloud.

## Expected Outputs

After a successful run, the `outputs` folder should contain:

- `category_summary.csv`
- `region_summary.csv`
- `revenue_by_region.png`

These files are generated by R and are ignored by Git so that the repository remains clean and reproducible.

## Limitations

- The dataset is small and synthetic, so findings should not be treated as evidence about a real business.
- Revenue is calculated before tax, discounts, returns, and operating costs.
- The chart is descriptive and does not establish causation or forecast future sales.
